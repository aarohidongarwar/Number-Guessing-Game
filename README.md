# 🎯 Number Guessing Game

A fun **Python console game** where players try to guess a randomly generated number!  
The game allows you to **choose your own range** and **tracks your score** based on how many attempts you take.

---

## ✨ Features
- Choose your own number range 🎚️  
- Keeps track of attempts (score) 🔢  
- Gives hints (“too high” / “too low”) 📉📈  
- Simple and interactive for beginners 🧩

---

## ▶️ How to Run
1. Make sure you have **Python 3** installed.
2. Download or clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Number-Guessing-Game.git
   ```
3. Navigate into the folder:
   ```bash
   cd Number-Guessing-Game
   ```
4. Run the game:
   ```bash
   python main.py
   ```
